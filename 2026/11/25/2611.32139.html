Decision support framework for mitigating failure demand in healthcare

low Katariina Timonen, Mariia Kozlova, Roman Stepanov, Julian Scott Yeomans · stat.AP · 25 Nov 2026
Combines cost-benefit modelling with Monte Carlo simulation and Simulation Decomposition to support healthcare failure-demand decision making.

Abstract

Failure demand studies in healthcare are, by nature, observational field studies conducted by social scientists. Historically, these practices have neglected any follow-on analysis by economists, data analysts, or mathematicians. In this paper, we argue that the mitigation of failure demand can only be effectively navigated through analytical cost-benefit modelling conducted in conjunction with a comprehensive uncertainty-sensitivity analysis. Using an existing failure demand field study as the starting point, we demonstrate how such a follow up analysis can be conducted and formulate a pragmatic decision support methodological framework that can be disseminated to the researchers and practitioners throughout the broad healthcare field. The framework emanates from classical cost-benefit modelling that is then supplemented with Monte Carlo simulation in combination with the groundbreaking Simulation Decomposition (SimDec) method. The SimDec results reveal additional insights critical for decision making that could not be readily uncovered by any other existing techniques. While SimDec’s methodological framework is straightforward to implement using various open-source computer code packages, this paper shows how non-technical healthcare practitioners can easily conduct an entirely congruent analysis via the freely-accessible web dashboard interface or the downloadable spreadsheet template.
