Revisiting Generalized Median Estimators: Exact Bitwise Computation and Gray Code Acceleration

low Robin Nunkesser · stat.CO · 23 Nov 2026
Develops exact exhaustive algorithms for generalized median estimators using Gray-code subset enumeration, fast selection, and floating-point error bounds.

Abstract

Generalized median estimators evaluate the median of a symmetric kernel over all $M = \binom{n}{k}$ subsets of size $k$. Exhaustive evaluation was considered impractical even for $n = 29, k = 5$ ($M = 118,755$), prompting stochastic subsampling (Wilde and Grimshaw, 2013). We show that this barrier is computational, not combinatorial: storing all subsets requires $\Theta(kM)$ space, whereas stateful enumeration uses $\mathcal{O}(k)$ auxiliary state and retains only $M$ kernel values. We combine two exhaustive traversals with three-way Quickselect and a deterministic median-of-medians fallback, giving worst-case $\mathcal{O}(M)$ selection. Gosper’s successor takes $\mathcal{O}(k)$ kernel work per subset for $n < w$; a Revolving Door Gray code changes one element out and one in, enabling $\mathcal{O}(1)$ kernel updates between recalibrations and $\mathcal{O}(M + kM/P)$ total time. We derive floating-point error bounds for the location ($h_1$) and mean-centered sample variance ($h_2$) kernels and their resulting median. For $n = 29, k = 5$, our ANSI C implementation evaluates all $118,755$ subsets in $0.74$ ms and $0.71$ ms, respectively. A direct C sweep places the crossover with partial lexicographic unranking at approximately $18,000$-$23,000$ subsets ($15\%$-$19\%$ of $M$), below the $32,160$-$45,420$ subsets required by Wilde and Grimshaw’s sequential approximation at $\epsilon = 0.01$.
