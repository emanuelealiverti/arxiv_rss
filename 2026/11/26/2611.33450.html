APEX: Agentic Platform for Ensemble eXploration

low Xiaodong Luo · stat.AP · 26 Nov 2026
APEX is a platform for configuring, validating, and comparing ensemble-based experiments on subsurface models, with cost estimation and provenance tracking.

Abstract

Ensemble-based methods provide a practical framework for history matching, prediction, and optimization of subsurface models. In methodological studies, however, performance is rarely assessed from a single run. Comparisons typically span cases, configurations, and random seeds, while each evaluation may require an expensive external simulator. Keeping such studies computationally bounded, auditable, and reproducible therefore requires more than implementing a numerical method: experiments must be validated before execution, computational costs estimated, repeated runs organized consistently, and configurations and outputs made traceable. To address these needs, we developed APEX (Agentic Platform for Ensemble eXploration), an open-source Python platform that provides a common framework for configuring, validating, executing, recording, and comparing ensemble-based experiments. APEX is organized around three concepts: an experiment defines what is executed, a run records a single execution, and a study coordinates and compares multiple experiments or runs. Experiments are specified through validated configurations, which can also be generated by a planner agent. Before execution, APEX estimates the maximum number of forward simulations required. If the estimate exceeds a user-defined threshold, submission is held for approval. Each run records provenance information, while studies repeat problems across variants and paired replicates and compare results using paired statistical analyses. Scientific and computational components, including methods, simulators, metrics, and optimizers, are implemented as plugins. A command line interface, Python client, REST service with a web interface, and tools for language model agents access these capabilities through a common service layer.
