evgmrf: An R Package For Gaussian Markov Random Field Extreme Value Models

medium Benjamin D. Youngman, Ayu Shabrina · stat.ME, stat.CO · 16 Nov 2026
Provides an R package for fitting spatially varying extreme value models using Gaussian Markov random fields.

Abstract

We introduce \textsf{evgmrf}, an \textsf{R} package for fitting spatially varying extreme value models using Gaussian Markov random fields (GMRFs). The package supports the generalized extreme value distribution for block maxima, the generalized Pareto distribution for threshold exceedances, the Poisson–GPD point-process model, and the $r$-largest order-statistics model. Distributional parameters may vary over regular spatial grids or arbitrary regions that can be represented by a valid adjacency matrix, with optional fixed effects and covariate dependence. Spatial structure is represented through intrinsic conditional autoregressive, proper conditional autoregressive, and Besag–York–Molli'{e} 2 models, which are extended with non-Gaussian random-effect distributions. Estimation uses penalized likelihood with smoothing or dependence hyper-parameters estimated using a Laplace approximation, exploiting sparse precision matrices for computational efficiency. The package provides methods for model summaries, spatial visualization, prediction on link and response scales, estimation of extreme quantiles, and uncertainty quantification in the form of approximate standard error estimates, or via simulations from parameter sampling distributions. Examples based on gridded and county-level precipitation data illustrate the use of the package for spatial modelling of environmental extremes. \textsf{evgmrf} provides a unified, accessible framework for extreme value analyses in which distributional parameters exhibit structured spatial variation.
