Super Learner: A Practical Tutorial

low Eliezer Pita Zambrano, Miguel Angel Luque-Fernandez · stat.ME · 13 Nov 2026
Provides a practical tutorial for constructing and tuning Super Learner ensembles in R.

Abstract

The selection of an optimal predictive model is a pervasive challenge in biostatistics and epidemiology. Relying on a single a priori algorithm risks overfitting and reduced generalizability when applied to new settings. Super Learner is a flexible ensemble machine-learning method that mitigates these risks by combining multiple candidate algorithms into a single prediction model. Using cross-validation, it defines a weighted combination of learners that minimizes a specified loss function, ensuring performance asymptotically equal to or better than the best candidate algorithm. This tutorial provides a comprehensive, practical guide to implementing Super Learner in R for applied researchers. Using a simulated epidemiological dataset with a binary outcome, we demonstrate the step-by-step construction of the ensemble. We cover the foundational statistical concepts, basic implementation, evaluation through cross-validation, hyperparameter tuning, feature screening, and performance optimization for metrics such as the Area Under the ROC Curve (AUC). Additionally, we detail advanced usage, including computational parallelization and the integration of custom algorithms and screening procedures. The guide also includes a consolidated section on best practices for specifying SL, covering loss function selection, effective sample size determination, CV scheme definition, library curation, and discrete vs. ensemble SL decisions, plus a practical reference to the caret package for model preprocessing and comparison. This guide equips epidemiologists and clinical researchers with the tools to confidently incorporate robust machine learning techniques into their predictive modeling workflows.
