An exact test for the mixed membership stochastic block model


Sourav Majumdar
[stat.ME]

We present the first finite-sample goodness-of-fit test for the mixed membership stochastic block model (MMSBM). Using algebraic statistics theory, we derive a Markov basis that lets a Metropolis-Hastings sampler explore exactly the set of networks compatible with a fitted MMSBM. The resulting exact $p$-value, based on a partial conjunction statistic, requires no asymptotic approximations. Simulations show nominal size and strong power against misspecified block numbers and connection patterns.
