We present NEVEN, an open-source infrastructure that embeds R, Julia, Python, Quarto, and JavaScript visualization libraries into Excel through native worksheet formulas. Users run econometric estimators, solve differential equations, and compile reproducible reports using expressions such as =R.MR_Lineal(...), =J.Optimize(...), and =P.ai_call(...), without procedural programming or external application switching. The platform offers over 70 R statistical procedures, 70 high-level Julia procedures backed by more than 200 mathematical functions, and full Python 3 integration for statistical computing and numerical analysis. Each language runtime runs in an independent operating-system process connected to the Excel XLL host via Windows Named Pipes and Protocol Buffers. Fatal errors terminate only the affected child process, leaving Excel operational. A static security sandbox checks user code against 25-30 restricted patterns per language, blocking shell execution, file deletion, unauthorized network access, and dynamic evaluation through five bypass-prevention mechanisms validated by 133 tests. An embedded WebView2 engine displays interactive Plotly charts, D3.js network and hierarchical visualizations, Leaflet maps, pivot tables, LaTeX notation, PDF documents, and Pluto.jl reactive notebooks through a unified formula, =NEVEN.v(). The docked NEVEN Studio environment offers nine specialized modules, including a Chart Gallery with 325 templates, an in-memory DuckDB SQL console, a retrieval-augmented AI assistant, and a multi-language script editor with English and Spanish localization. Econometric estimates match published benchmarks to four decimal places, while Julia linear algebra decompositions achieve machine-precision accuracy (relative error below 10^-14). Released under GNU General Public License v3, NEVEN includes 342 automated unit, property-based, and integration tests.
