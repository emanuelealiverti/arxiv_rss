Path sampling-based stratification algorithms such as Transition Interface Sampling (TIS) enable the evaluation of kinetic rate constants and mechanisms of complex molecular rare event transitions. By sampling only short dynamical trajectories, TIS allows constructing an estimate of the unbiased dynamics by reweighting the interface path ensembles. In the past decades several methods have been developed and applied to achieve such path reweighting, based on statistically optimal use of the trajectory data. Why and how this reweighting exactly works has been underexplored up to now. Here we discuss several different schemes to compute the reweighted path ensemble (RPE), notably point-wise matching, Weighted Histogram Analysis Method (WHAM), Multistate Bennett Acceptance Ratio (MBAR), variance based reweighting (VBR) and survival analysis reweighting (SAR). We show that except for the point-wise matching the other methods are leading to the same outcome, and in fact can be seen as identical. Moreover, the SAR links to a well-established nonparametric maximum-likelihood estimator of product-limit form. This allows a synthesis of all path reweighting schemes, identifying the common underlying nature. All schemes follow from this common origin. We illustrate the reweighting with some simple examples, and show that care has to be taken when applying WHAM, if the number of interfaces and histogram bins do not match.
