AIDA is an R package that provides tools for the analysis of interval-valued data, including construction, visualization, robust estimation, and explainable outlier detection. The package is built around the intData class and is designed to support methodological research and applied workflows involving interval-valued data. AIDA implements methods for symbolic covariance estimation based on the Mallows distance, robust estimation via the Interval Minimum Covariance Determinant estimator, and explainable outlier detection using Shapley values. The package also includes visualization tools to support interpretation of the results and several interval-valued datasets.
